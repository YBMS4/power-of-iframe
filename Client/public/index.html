Power of Iframe Test

Explainations

The Form bellow is not hosted on this page but in an <Iframe> Tag, and since the source is from a different domain, you can't access it with document.querySelector("iframe").contentWindow.document in the JS or see its content in the navigator Inspector.
Now try opening the inspector you'll notice in the console a Warning message with a cross-orign error, meaning that you can't access the page in the <Iframe>'s elements via JS but you can still see them in the inspector.
